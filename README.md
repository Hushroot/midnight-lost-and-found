# Midnight Lost & Found

A spooky browser game where you cover the night shift at a station’s lost-property window. Ghost visitors describe their missing belongings, and you inspect the shelf items to decide what to hand over.

## Play

[Open the game](https://hushroot.github.io/midnight-lost-and-found/)

Read each visitor’s clue, inspect the four items, and hand over your choice. Correct returns increase your score; wrong returns add a mistake. Use **Next visitor** to continue.

## Run locally

1. Download this repository using **Code → Download ZIP**, then extract it.
2. Open `index.html` in your browser.

No installation or build step is needed.

## Built with

- HTML for the page structure
- CSS for the dark station theme
- JavaScript for inspection, visitor changes, and scoring
